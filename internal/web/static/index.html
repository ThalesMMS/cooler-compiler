Educational developer tool

          
Cooler Compiler Lab

          
Explore how a COOL program becomes executable code, one compiler phase at a time.

        

      


      

        
How it works

        
Your source moves through lexical analysis, parsing, semantic analysis, stack IR, pseudo-assembly, and an educational virtual machine. Each phase exposes its artifacts so you can inspect what the compiler produced.

        

          Lexer→
          Parser→
          Semantic→
          IR→
          VM
        

      


      

        
Controls

        

          
Next Phase
Advances exactly one compiler phase and preserves its intermediate state.

          
Compile
Completes all remaining phases without executing a VM instruction.

          
Run
Completes pending compilation, then runs until the program halts or reaches a breakpoint.

          
Step
Completes pending compilation, then executes exactly one VM instruction.
