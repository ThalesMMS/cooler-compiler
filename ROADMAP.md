# Roadmap

Cooler Compiler is a local-first educational compiler and workbench. The
project focuses on clear language behavior, reproducible local execution, and
tools that help learners inspect compilation and runtime behavior.

## Current scope

The current release line provides the COOL compiler, a Go virtual machine,
command-line tools, a graphical workbench, language-server support, debugging,
and portable reports. Optional course-assignment modes add reference-format
output, a generated front-end, and MIPS assembly with an embedded simulator.
These modes are described in the [course assignment guide](docs/course-assignments.md).

## Possible future directions

Potential areas for future work include additional educational backends,
improved editor integrations, and broader desktop packaging. These directions
are exploratory and do not change the supported behavior of the current
release.

Released changes are listed in [CHANGELOG.md](CHANGELOG.md). Product behavior
and compatibility boundaries are described in the project documentation.
